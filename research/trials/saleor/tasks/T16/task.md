# A command to provision a new site

We are starting to host several shops from one Saleor deployment, and today an operator has to create the second `Site` row and its `SiteSettings` row by hand in a shell, and forgetting the settings row leaves a site that breaks the shop queries. Please add a management command `create_site <domain> <name>` (in the `saleor.site` app, so it is run with `python manage.py create_site tenant.example.com "Tenant shop"`) that creates the new site together with a settings row holding the default values, so the site is immediately usable. It prints a line with the new site's domain, and it fails with a `CommandError` (creating nothing) when a site with that domain already exists, ignoring case. Existing sites and their settings must not be touched.
