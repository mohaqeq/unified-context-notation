Several places scan a string for a marker and then need the matched ranges as slices rather than start offsets. Please add `findall_slices(substr, in_str)` to `sqlfluff.core.helpers.string`. It should be a generator that yields one `slice(start, stop)` for every occurrence of `substr` in `in_str`, in order, using the same matching rules as the existing `findall` (overlapping matches are all reported, and nothing is yielded if either input is empty).
