Please add `slice_contains(s: slice, i: int) -> bool` to `sqlfluff/core/helpers/slice.py`. It should return True when the index `i` falls inside the closed slice `s` (start inclusive, stop exclusive), and False otherwise, so `slice_contains(slice(2, 5), 4)` is True while `slice_contains(slice(2, 5), 5)` is False. A zero-length slice contains nothing. For an open slice (start or stop is None) it should raise an AssertionError, like the other helpers in that module.
