Violation descriptions can be long, and tools that embed them in fixed-width output (editor panels, terminal tables) currently have to wrap them by hand. Please add a method `desc_lines(width: int) -> list[str]` to `SQLBaseError` (in `sqlfluff/core/errors.py`) that returns the violation's description (as given by `desc()`) wrapped into lines that are each at most `width` characters, breaking on whitespace. A short description should come back as a single line, and subclasses such as `SQLLintError` should get the method too.
