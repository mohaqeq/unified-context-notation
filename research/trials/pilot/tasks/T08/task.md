We want to be able to ask a parsed tree which comments carry a `noqa` directive without going through the linter. Please add a method `get_noqa_comments()` to `BaseSegment` (`sqlfluff.core.parser.segments.base`) that returns, in source order, a list of the `inline_comment` and `block_comment` segments at or below that segment whose content is a noqa directive. A comment counts when, after removing the comment markers (`--`, `#`, or `/* ... */`) and surrounding whitespace, its text starts with `noqa` (case-sensitive, as in the linter); where a comment chains several `--` sections the last one is what counts, e.g. `-- note -- noqa: LT05`. Comments that merely mention noqa, such as `-- see the noqa docs`, are not included.
