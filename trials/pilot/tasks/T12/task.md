`split_comma_separated_string` in `sqlfluff.core.helpers.string` cleans up string input (strips whitespace, drops empty items) but returns a list input untouched, so `["a ", "", " b"]` comes back with the stray whitespace and empty entry, and a tuple input trips an assertion. Please make it treat lists and tuples the same way as strings: each item stripped, empty items removed, result always a new `list`. String behaviour must stay as it is.
