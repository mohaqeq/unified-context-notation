We need a small helper in `sqlfluff.core.parser.helpers`: `references_overlap(first, second)`, taking two object references as tuples of strings (e.g. `("schema", "tbl")`) and returning True if they could point at the same object. That is the case when the tuples are equal, or when one is a trailing part of the other (so `("tbl",)` and `("schema", "tbl")` overlap, and `("b", "c")` overlaps `("a", "b", "c")`, but `("schema",)` does not overlap `("schema", "tbl")`). Comparison is exact and case-sensitive, and an empty tuple never overlaps anything. This is the same matching idea RF01 uses for table references.
