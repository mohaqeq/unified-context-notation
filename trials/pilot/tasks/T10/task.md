Users of `sqlfluff.api.lint` get back a list of violation dicts and then each write their own code to print them. Please add `format_violations(violations)` to `sqlfluff.api.simple` and export it from `sqlfluff.api`. It takes that list and returns a single plain-text string (no colour codes, no trailing newline) with one line per violation, in the same layout the CLI uses for a violation: `L:` and `P:` followed by the start line number and position right-aligned to width 4, then the rule code right-aligned to width 4, each separated by ` | `, then the description, followed by ` [rule_name]` when the violation has a non-empty name. An empty list gives an empty string; descriptions are not wrapped.
