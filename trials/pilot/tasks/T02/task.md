Bug reports for the Python API keep asking which sqlfluff and Python build the reporter is running. Please add a function `version_info()` to `sqlfluff.api.info` that returns a dict with three string entries: `"sqlfluff"` (the installed sqlfluff version, same as `sqlfluff.__version__`), `"python"` (the interpreter version as `major.minor.micro`, e.g. `3.11.4`), and `"implementation"` (the Python implementation name, e.g. `cpython` or `pypy`, lowercase).
