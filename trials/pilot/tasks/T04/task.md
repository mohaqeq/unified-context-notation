Please add `parse_dotted_assignments(raw: str) -> dict` to `sqlfluff.core.helpers.string`. It takes a comma separated string of `dotted.key=value` pairs, e.g. `"rules.LT01.foo=1, core.dialect=ansi"`, and returns a nested dict with the dotted keys expanded and all values left as stripped strings: `{"rules": {"LT01": {"foo": "1"}}, "core": {"dialect": "ansi"}}`. Whitespace around keys, values and commas is ignored, an empty string gives `{}`, and keys sharing a prefix are merged into the same sub-dict. A pair with no `=` or with an empty key part (e.g. `"a..b=1"`) should raise `ValueError`.
